# Issue tracker: GitHub Issues

Issues for this repo live in [GitHub Issues](https://github.com/si13n/si13-android/issues).

## How skills use it

Skills like `to-spec`, `to-tickets`, and `diagnose` write findings as GitHub Issues and read from them.

- **New issue**: `gh issue create --title "..." --body "..."` (or via the GitHub UI)
- **Link to issue**: use `#<number>` or the full GitHub URL

## Labels and triage

If the `triage` skill is installed later, it will manage issue labels and queue. For now, use GitHub's built-in labels.

## Pull requests

PRs to this repo are treated as code, not as a request surface for the skills. Code review and testing happen in CI and review comments. File an issue if you want a feature; open a PR to implement it.
